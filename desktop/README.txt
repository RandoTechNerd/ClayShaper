ClayShaper — ceramic slicer
===========================

TO RUN
------
Double-click  ClayShaper.exe

ClayShaper opens in its own window. Close the window to quit — that's it.
No install, no setup, nothing to configure.

Windows may warn about an unrecognised app (it isn't code-signed yet).
Click "More info" -> "Run anyway".

FIRST RUN
---------
The first launch takes about 20-30 seconds and needs internet once, while it
sets itself up. After that it starts in a couple of seconds and works offline
— your models never leave your computer.

WHAT'S INSIDE
-------------
* Slice STL       - drop in your own STL, or use the 5 included samples
* Design          - parametric bowls & vases, textures, the Virtual Wheel
                    (draw a profile, spin it), and Handles (9 styles)
* Validate G-code - check any file before it reaches the machine

Tuned for the Eazao Potter (165 x 165 x 280 mm). You can add your own
printer from the sidebar.

TROUBLESHOOTING
---------------
* Window didn't open? Make sure Chrome or Edge is installed — ClayShaper
  uses one of them to draw its window. Without either, it falls back to
  your default browser at http://127.0.0.1:8770
* Antivirus quarantine? Apps built this way are sometimes false-positived.
  The full source is public: github.com/RandoTechNerd/ClayShaper
