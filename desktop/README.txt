ClayShaper
A free ceramic slicer for clay 3D printers
==========================================

HOW TO START IT
---------------
Double click  ClayShaper.exe

ClayShaper opens in its own window. Close the window when you are done.
There is nothing to install and nothing to set up.

If Windows shows a blue warning box, click "More info", then "Run anyway".
That box appears because the app is not code signed yet, which is just an
expensive certificate. The full source code is public if you want to check
it: github.com/RandoTechNerd/ClayShaper

THE FIRST LAUNCH
----------------
The first time you open ClayShaper it takes about 20 to 30 seconds and needs
internet, while it sets itself up. Every launch after that opens in a couple
of seconds and works offline. Your models never leave your computer.

WHAT YOU CAN DO
---------------
Slice a 3D model
   Load your own STL, or start from one of the five included samples, and
   get a clay toolpath. Vase mode prints the wall as one unbroken spiral.
   The staggered base grips instead of peeling. Fold softening helps
   crumpled shapes print.

Design without a 3D model
   Build bowls and vases with simple sliders, add ripples or twists, or use
   the Virtual Wheel: draw the side profile of a pot, press spin, and watch
   it become a real toolpath. There is also a handle maker with nine shapes.

Check your file before you print
   Every file is checked for walls printing into thin air, over extrusion,
   speeds outside your machine limits, missing clay start codes, and how
   much clay you will use in grams.

Set up for the Eazao Potter (165 x 165 x 280 mm). You can add your own
printer from the sidebar.

IF SOMETHING GOES WRONG
-----------------------
Window did not open?
   Make sure Chrome or Edge is installed, since ClayShaper uses one of them
   to draw its window. Without either, it opens in your default browser at
   http://127.0.0.1:8770

Antivirus removed the file?
   Apps built this way are sometimes flagged by mistake. The source code is
   public so you can build it yourself if you prefer.
